Lección: los tres pilares de una página web

1. HTML

HTML es el esqueleto de la página. Con él se crean los títulos, párrafos, imágenes, botones y enlaces.

2. CSS

CSS es el diseño. Con él se cambian los colores, las fuentes, los tamaños y la posición de cada elemento.

3. JavaScript

JavaScript es el comportamiento. Con él la página reacciona a los clics, guarda datos y cambia su contenido.
